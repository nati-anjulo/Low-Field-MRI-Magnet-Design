MAGNET ARRAY OPTIMIZATION - INSTALL
====================================

What you need:
- Python 3.8+
- NVIDIA GPU with CUDA

Install packages:
    pip install -r requirements.txt

Or manually:
    pip install numpy scipy matplotlib plotly pytictoc
    pip install cupy-cuda12x    # use cupy-cuda11x for CUDA 11
    pip install magpylib        # optional, for validation

Test it works:
    python -c "import cupy as cp; print(cp.array([1,2,3]))"

------------------------------------
PRECOMPUTED FIELD
------------------------------------

Before optimizing, generate a field lookup file:
1. Open precompute/Generate_Precomputed_Field_Batched_analytical.ipynb
2. Set your grid size (should be 1.5x your design size)
3. Run it - creates Precalc_field_*.npz
4. Put that file in Magnet_design/

------------------------------------
RUN OPTIMIZATION
------------------------------------

Elliptical bore:
    jupyter notebook ellipse_optimization_usage.ipynb

Cylindrical bore:
    jupyter notebook cylindrical_optimization_usage.ipynb

------------------------------------
3D VIEWER
------------------------------------

Built-in (no extra install needed):
    visualization.show_magnets_plotly(config, magnet_size)

If the plot doesn't show, it auto-opens in your browser.
To force browser: add show=True

Magpylib viewer (if you have it installed):
    import visualize_configuration as VS
    VS.rad_halbach_Design_rad(magnet_size, config).show()

------------------------------------
COMMON ISSUES
------------------------------------

"No module named cupy"
    pip install cupy-cuda12x

"CUDA out of memory"
    Restart Jupyter kernel, or run:
    cp.get_default_memory_pool().free_all_blocks()

3D plot not showing
    The viewer tries browser fallback automatically.
    Or use: visualization.show_magnets_plotly(config, size, show=True)
