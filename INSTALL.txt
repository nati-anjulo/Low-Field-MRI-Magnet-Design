================================================================================
MAGNET ARRAY OPTIMIZATION - INSTALLATION GUIDE
================================================================================

This project contains GPU-accelerated simulated annealing optimization for
permanent magnet array design. Two geometry types are supported:
  - Elliptical cylinder (ellipse_opt package)
  - Cylindrical octant (cylindrical_opt package)

--------------------------------------------------------------------------------
SYSTEM REQUIREMENTS
--------------------------------------------------------------------------------

1. Python 3.9 or higher
2. NVIDIA GPU with CUDA support
3. CUDA Toolkit 11.x or 12.x installed

--------------------------------------------------------------------------------
REQUIRED PACKAGES
--------------------------------------------------------------------------------

Package         Version     Purpose
-----------     -------     -----------------------------------------------
numpy           >=1.20      Array operations, data handling
cupy            >=12.0      GPU-accelerated computing (like numpy but on GPU)
scipy           >=1.7       Math routines used in calibration
matplotlib      >=3.5       2D plotting (cost curves, field plots)
plotly          >=5.0       3D interactive plots of magnet positions
magpylib        >=4.0       Magnetic field validation (cross-checks results)
pytictoc        >=1.5       Timing how long optimization takes

--------------------------------------------------------------------------------
INSTALLATION
--------------------------------------------------------------------------------

Option 1: Install from requirements.txt
    pip install -r requirements.txt

Option 2: Install packages individually
    pip install numpy scipy matplotlib plotly pytictoc

    # For CUDA 12.x:
    pip install cupy-cuda12x

    # For CUDA 11.x:
    pip install cupy-cuda11x

Option 3: Using conda
    conda install numpy scipy matplotlib plotly
    pip install cupy-cuda12x pytictoc

--------------------------------------------------------------------------------
VERIFY INSTALLATION

--------------------------------------------------------------------------------
PRECOMPUTED FIELD DATA
--------------------------------------------------------------------------------

The optimization needs a precomputed magnetic field lookup table (.npz file).
This speeds up optimization by pre-calculating the field from a single magnet
at many grid points, so we can quickly look up field values during optimization.

**Generate your own precomputed field:**
    1. Open: precompute/Generate_Precomputed_Field_Batched_analytical.ipynb
    2. Adjust parameters as needed:
       - Grid size (larger = more memory but handles bigger designs)
       - Magnet properties (Br, demagnetization factor)
       - Step size (smaller = more accurate but larger file)
    3. Run the notebook - it will create a Precalc_field_*.npz file
    4. Place the .npz file in the Magnet_design/ folder

**What the .npz file contains:**
    - Bxyzvalue: B-field (x,y,z) at each grid point
    - Ref_grid: Grid coordinates
    - step_size: Distance between grid points (e.g., 1mm)

--------------------------------------------------------------------------------
TROUBLESHOOTING
--------------------------------------------------------------------------------

1. "No module named 'cupy'"
   -> Install cupy with correct CUDA version: pip install cupy-cuda12x

2. "CUDA out of memory"
   -> free the GPU memory
   -> Restart your Jupyter kernel or reduce n_magnets/n_sample_points

3. Grid size recommendation
   -> Grid size should be 1.5x the largest dimension of your design
   -> Example: 300mm bore design needs at least 450mm grid
